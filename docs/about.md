# About Multi-Tenant NestJS Kit

## Who maintains it

Multi-Tenant NestJS Kit is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/multi-tenant-nestjs-kit](https://github.com/mediuswareltd/multi-tenant-nestjs-kit).

## Why it exists

A NestJS starter with multi-tenant database support, Docker Compose, and migration-ready setup.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/multi-tenant-nestjs-kit/
