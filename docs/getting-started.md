# Getting started

Install and run **Multi-Tenant NestJS Kit** locally.

## Prerequisites

- Working knowledge of TypeScript
- Git and a terminal

## Install

```bash
cp env.example .env
yarn install
```

## Quick start

```bash
docker-compose up -d
yarn migration:run
yarn start
```
