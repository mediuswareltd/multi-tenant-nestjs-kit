# Guide

## What it is

A NestJS starter with multi-tenant database support, Docker Compose, and migration-ready setup.

## Stack

`NestJS`, `TypeScript`, `PostgreSQL`, `Docker`

## Capabilities

### Multi-tenant ready

Platform + tenant database foundations.

### Docker Compose

Local stack up with one command.

### Migrations

Yarn migration workflow for both DBs.

### NestJS baseline

Foundational modules for production apps.
