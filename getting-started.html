Getting started ​

Run Multi-Tenant NestJS Kit on your machine.

1. Quick start ​

With Docker ​

bash
cp env.example .env
docker-compose up -d
yarn migration:run
yarn start

Local Setup ​

  1. Install dependencies
bash
yarn install
  1. Create PostgreSQL databases
sql
CREATE DATABASE platform;
CREATE DATABASE tenant;
  1. Configure environment
bash
cp env.example .env
  1. Run migrations (both databases)
bash
# Run both databases
yarn migration:run

# Or separately
yarn migration:run:platform
yarn migration:run:tenant
  1. Start server
bash
yarn start:dev

Browse http://localhost:5000
